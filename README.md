# fake_news_detection
Natural Language Processing Project

This project explores the automated detection of political misinformation using the LIAR dataset. It features a comprehensive comparative analysis, evolving from traditional Machine Learning algorithms to state-of-the-art architectures based on the Transformer model.

The following models were used in the analysis:

* Traditional Models (Naive Bayes, SVM, Random Forest): Simple, fast, and act as a baseline.
* Deep Learning (LSTM): Good for understanding the order of words in a sentence.
* Transformers (BERT, RoBERTa): The current "gold standard" that understands the full context and relationship between all words.
